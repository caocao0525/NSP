How to generate Figure 7a:
- Run `plot_final_result_all.py` will generate `{metric}_heatmap_clustered.pdf` (metric = ACC, AUC, F1) under fig directory. File path is hard coded in the script. (load `all_results.txt`)

```bash
python plot_final_result_all.py
```


How `all_results.txt` was generated:
- all_results.txt is generated by correcting last line of `eval_results.txt` for each A vs B cell types.
