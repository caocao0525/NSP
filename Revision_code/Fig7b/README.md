How to generate Figure 7b:
- Run `motif_clustering.py` will generate `motif_cluster.pdf`, `motif_dendrogram.pdf`, `motif_dtw.pdf` and `motif_umap.pdf` under `vis_results` directory.

```bash
python motif_clustering.py -i init_df.csv -o vis_results
```


How `init_df.csv` was generated:
- init_df.csv is generated by `find_motifs.py` on ESC vs bloodTcell.
```bash
python find_motifs.py \
        --data_dir "${current_DIR}" \
        --predict_dir "${current_DIR}/out_pred" \
        --window_size 10 \
        --min_len 5 \
        --pval_cutoff 1e-6 \
        --min_n_motif 2 \
        --align_all_ties \
        --save_file_dir "${current_DIR}/out_motif_005" \
        --verbose
```
